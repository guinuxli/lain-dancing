# Lain Dancing

A simple Raylib joke that i made using C.

## Instalation

This project was made in Linux, but you probably can compile it to run on Windows
since Raylib is CrossPlatform.

```
git clone https://github.com/guinuxli/lain-dancing.git
cd lain-dancing
make
```

## Usage

after compile you should be able to run just by using "./lain" or "make run".
